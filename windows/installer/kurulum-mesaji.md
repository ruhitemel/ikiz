# İkiz kuruluyor

İkiz, bilgisayarındaki aynı dosyaların kopyalarını bulur. Gereksiz kopyaları gösterir; sen onaylamadan hiçbir dosyayı silmez.

Programda neler var:

- **Anında arama** — dosya adı, türü veya yolu yaz, sonuçlar hemen görünsün.
- **Çift kopyalar** — aynı ad, boyut ve türdeki dosyalar grup grup listelenir.
- **Hızlı seçim** — Tümünü seç, Kopyaları seç, Panoya al, Sil, Adlandır.
- **Güvenli silme** — önce liste görürsün; varsayılan hedef Geri Dönüşüm Kutusu'dur.
- **Güncelleme** — kurulumlu sürüm yeni sürümleri GitHub üzerinden kendiliğinden denetler.

Kurulum için **İleri** düğmesine bas.
